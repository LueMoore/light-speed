# 🪐 光速渲染实验 (Light Speed Renderer)

> 如果光速只有 1 米/秒，且不考虑相对论效应，世界会变成什么样？

这是一个基于 WebGL 和片元着色器（Fragment Shader）的**第一性原理物理渲染实验**。它没有使用任何预先烘焙的动画，而是把经典物理的光传播方程直接写进了显卡渲染管线中，实时计算每一束光线到达你眼睛所需的时间。

## ✨ 核心特性

- **🕰️ 延迟视觉（Retarded Time）**：光线飞向你眼睛需要时间。你在画面中看到的，其实是物体在过去某一时刻的残影。
- **👻 幽灵阴影**：当光源发光时，物体挡住了光。等光飞到地面，物体已经转走了。于是地面上会留下随历史轨迹扭曲的“残影阴影”。
- **🌈 延迟着色（Delay Shading）**：点击左下角的按钮，画面会切换为“时间热力图”。颜色越红，代表这束光在空间中飞行的距离越远、时间越久。
- **🔍 真实光影**：利用 Raymarching（光线步进）算法实时计算软阴影与高光，没有任何模型面片。

## 🚀 如何运行

本项目纯前端实现，零依赖，零构建：
1. 下载仓库中的 `index.html` 文件。
2. 直接双击用 Chrome / Edge 等现代浏览器打开即可。
3. 拖动面板中的 `c` 滑块，感受光速变慢带来的视觉扭曲。

## 🎮 操作说明

- **鼠标拖动**：环视四周。
- **W / A / S / D**：在场景中自由移动相机（仿佛你是一个无视物理法则的观测者）。
- **滑块**：调整光速（从 0.5 m/s 到近乎无限大）。
- **按钮**：切换延迟着色模式或暂停世界的时间。

## 🧠 物理原理简述

渲染器在计算每一个像素时，都在求解一个时间回溯方程：
`当前时间 - (光线飞行距离 / 光速) = 光源发光时刻`

通过不断向视锥体前方步进（Marching），引擎会判断光线在飞行的途中是否撞上了历史位置的物体，从而还原出极度诡异但又绝对符合物理定律的画面。

## ⚠️ 性能与注意事项

- **极度吃显卡**：因为每一帧都在做海量的光线步进循环，建议使用**电脑端**独立显卡或性能较好的核显打开。
- **手机端警告**：如果在手机浏览器打开，可能会严重掉帧甚至导致设备发热。
- 如果画面卡顿，可以尝试缩小浏览器窗口，或在代码中降低 Raymarching 的步进次数。
